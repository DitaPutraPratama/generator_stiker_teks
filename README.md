# Generator Stiker Teks

Pembuat stiker dari teks, satu file HTML tanpa dependensi. Buka `index.html` di browser.

## Fitur

- Perataan teks: rata kanan-kiri, kiri, atau tengah
- Pilihan huruf, tebal, jarak tepi, dan jarak antar baris
- Sudut membulat dengan latar luar transparan
- Unduh sebagai PNG atau WebP (untuk stiker WhatsApp)
